# Mini ERP + CRM Portal - Frontend Application

Modern, minimalist enterprise frontend built with **React 18**, **Vite**, and **TypeScript**, styled after the **Shadcn UI Dashboard** design system.

---

## 🎨 Design Philosophy

- **Shadcn UI Aesthetic**: Clean, minimalist admin layout, subtle gray borders, crisp typography (Inter), badges, and clean modal dialogs.
- **Zero AI-Generated Gimmicks**: No tacky animations or bloated dependencies.
- **1-Click Role Switcher**: Quick login buttons on the login screen for effortless evaluation across `ADMIN`, `SALES`, `WAREHOUSE`, and `ACCOUNTS`.

---

## ⚡ Quick Setup & Execution

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
The frontend will start at **`http://localhost:3000`** with automatic API proxying to backend (`http://localhost:5000`).

### 3. Build Production Bundle
```bash
npm run build
```
